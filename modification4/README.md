## Baseline FRCNN VGG16

График функции потерь за 50 эпох:

![Функция потерь](frcnn_vgg16_losses.png)

График функции mAP@0.5 за 50 эпох:

![Метрика mAP@0.5](frcnn_vgg16_maps.png)

* Train Loss монотонно уменьшается.
* Test Loss сначала уменьшается, после $10$ эпох выходит на плато и после $30$ эпох начинает постепенно расти.
* После $10$ эпох **mAP@0.5** выходит на плато и практически не изменяется.

1. Растущий Test Loss на $>30$ эпохе при падающем Train Loss означает переобучение.
2. На $10-30$ эпохах **mAP@0.5** находится в промежутке $0.575-0.625$.
3. **mAP@0.5** достигает максимального значения на $28$ эпохе ($62.60$).
Это и есть состояние, при котором модель полностью обучена
